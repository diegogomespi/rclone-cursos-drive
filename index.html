Rclone Cursos Drive

Utilitário privado para copiar arquivos de uma pasta escolhida no computador para uma pasta específica do Google Drive.

O sistema apenas copia. Ele não apaga arquivos do computador nem do Google Drive.

Como funciona

  1. O proprietário autoriza o acesso usando a tela oficial do Google.
  2. O Rclone verifica arquivos locais estáveis e ignora downloads incompletos.
  3. Arquivos novos são copiados para a pasta configurada no Google Drive.
  4. Arquivos remotos diferentes nunca são sobrescritos automaticamente.

Uso de dados

O acesso ao Google Drive é usado exclusivamente para listar, comparar e copiar arquivos solicitados pelo próprio proprietário da conta. O aplicativo não vende, compartilha nem utiliza dados para publicidade.
